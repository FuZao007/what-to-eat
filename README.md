# 今天吃什么？ - 北邮沙河校区版 🍱

这是一个专为北京邮电大学（沙河校区）学生设计的随机美食推荐系统。

## ✨ 核心功能
- **校区定制数据**：内置沙河校区 A 楼、D 楼各层食堂真实菜单。
- **云端评价系统**：基于 Supabase 实现全校点评与评分同步。
- **个性化过滤**：支持自定义忌口关键词。
- **Q版 UI 设计**：二次元萌系风格，伴有浮动动画。

## 🛠️ 技术栈
- **前端**：HTML5, CSS3 (Tailwind CSS), JavaScript
- **后端**：Supabase (BaaS)
- **图标**：Lucide Icons

## 🚀 部署
本项目支持通过 Vercel, GitHub Pages 或腾讯云 EdgeOne 快速部署。
